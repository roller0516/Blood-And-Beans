# Blood & Beans 아트 디렉션

저장소 루트의 `CLAUDE.md`를 먼저 따른다. 아래 경로는 해당 루트 기준이다. 사용자가 새로 지정한 시안·범위가 이 문서보다 우선한다.

## 기준 자료 선택

- 갤러리 원본: `00__Docs/02__Art/02__UI/luigi-pc-ui-v2/blood-beans-luigi-portable.html`. 새 갤러리를 만들지 말고 요청받은 기존 항목을 수정한다. 이 파일과 `assets.zip`은 Git에서 제외될 수 있다.
- 최신 사용자 방향(2026-10-18): 공개 갤러리 `#night`의 **기존 캐릭터 시안**을 기준으로 한다. 원본은 같은 폴더의 `pcVampire0.png`~`pcVampire3.png` 및 다른 캐릭터 이미지다. `unity-concepts-v2/`와 현재 Unity 전체 UI는 너무 무겁다는 평가를 받았으므로 그대로 승인 기준으로 삼지 않는다. `light-ui-preview/`는 새 방향 검토용 생성 시안이며 최종 승인·Unity 구현 결과와 구분한다.
- 실제 제작 구조: `UI_UNITY_IMPLEMENTATION.md`, `ui-assets-refinement-provenance.json`, Unity의 현재 프리팹·Material·Sprite·폰트 참조. 문서가 오래되었으면 에디터와 파일에서 확인한다.
- 게임의 화면·표시 조건은 `00__Docs/01__Design/AGENTS.md`의 지침에 따라 기획서를 확인한다. 시각 작업에서 규칙 수치나 네트워크 권한을 바꾸지 않는다.

## 시각 방향

루이지 맨션에서 참고한 유령·카페 분위기를 기존 캐릭터 시안의 가벼운 UI로 해석한다. 반투명 보라색 패널, 얇은 연보라 외곽선, 흰색의 둥근 글자, 제한적인 연두 선택 표시를 기준으로 한다. 두꺼운 황동 프레임·녹색 가죽 보드·낡은 종이·클립·사슬·매달린 장식으로 무게를 더하지 않는다. 장면과 캐릭터가 주역이며 UI는 PC 화면의 시야와 여백을 확보한다. 새 시안을 검토받기 전에 프리팹 전체를 다시 리스킨하지 않는다.

주요 차이는 색만이 아니다. 제작 전에 대상 시안과 실제 화면의 패널 형태, 배치, 큰 제목/숫자, 아이콘, 표면 질감과 상태 표시를 대조한다. 임의의 기본 폰트·사각형 컨트롤로 대체한 뒤 시안과 같다고 보고하지 않는다.

현재 제작 폰트 역할은 제목 `Cafe24Ssurround`, 본문 `DoHyeon`, 숫자·영문 `LilitaOne`이다. 실제 TMP 참조와 라이선스 고지를 확인한다. 생성 이미지 속 글자를 실사용 폰트로 간주하지 말고 동적인 이름·숫자·설명은 별도 TMP로 구성한다.

## 제작과 재사용

- 현재 프로젝트의 `ui-ugui`, `sprite-editor`, `optimize-text-mesh-pro` 중 작업에 해당하는 스킬을 읽는다. Unity 조작은 프로젝트의 `unity-cli`로 수행한다.
- Scenario 스킬의 macOS/Unity 6000.3 예제는 현재 Windows/Unity 6000.5.9f1/URP 17.5와 API·도구 호환성을 확인한 뒤 적용한다. 기존 프로젝트의 CLI·어셈블리·패키지 규칙을 우선한다.
- 실제 적용 요청이면 기존 프리팹 GUID·Presenter·데이터·입력 연결을 유지한다. 공유 `UISurfacePart`, 카드·행·슬롯을 재사용하고 표현 차이는 Sprite·Material·프리팹 Variant로 분리한다. 새 화면 루트나 추상화 계층을 일괄 복제하지 않는다.
- 고정 배경·프레임·장식과 동적 텍스트·아이콘·게이지를 분리한다. 확장되는 패널은 9-slice, 반복 요소는 LayoutGroup과 재사용 부품으로 구성한다. 포장 이미지 하나로 UI 전체를 덮지 않는다.
- 낮·밤 플레이 시안은 실제 인게임 카메라 구도를 유지하며 UI를 교체한다. 정적 카페 그림을 실시간 3D 배경으로 설명하지 않는다. 캐릭터 선택의 실제 3D 모델·전용 카메라와 UI 배경 합성을 구분한다.
- CharacterStage 병합 시 카메라·Cinemachine·뷰포트·배경 Canvas 연결을 함께 확인한다. UI 구도를 복구한다는 이유로 팀원이 갱신한 메시·Material·조명 데이터를 통째로 되돌리지 않는다.
- CharacterStage 배경은 사용자가 지정한 기존 3D 카페를 사용한다. 이미지 배경으로 덮지 않는다. 새 설비·바닥이 전용 카메라의 레이어에 포함되는지 확인하고 수정은 무대 인스턴스/프리팹에 한정한다.
- 2026-10-18 추가 지시: 새 전체 시안의 배경 분위기도 `pcVampire2.png`의 보랏빛 밤·따뜻한 카페 조명으로 다시 맞춘다. 이는 배경 아트 방향 변경이며, 시안 PNG를 실제 CharacterStage 위에 덮으라는 의미로 해석하지 않는다. 실시간 3D 배경의 후속 제작과 UI 구현을 구분한다.
- 이미지 제작은 사용 가능한 `imagegen` 또는 설치된 Forge 이미지 스킬을 사용한다. 코드로 그린 그림은 사용자가 요청한 경우 등 해당 스킬의 적용 조건에 맞을 때만 사용한다. Sprite Forge 설치만으로 동영상 생성 서비스나 유료 API가 연결되었다고 간주하지 않는다.
- 시안에 필요한 UI용 입체 장식은 Sprite, Mesh, 실시간 렌더 중 실제 움직임과 비용에 맞게 선택한다. 요청하지 않은 월드 프랍은 작업 범위에 넣지 않는다.

## 확인과 전달

실제 저장된 프리팹으로 실행 화면을 확인한다. 한글 이름·긴 설명·숫자의 글자 경계, 선택/비활성/빈 상태, 실제 입력 컨트롤을 검사한다. PC 기준 1920×1080 및 프로젝트 지침의 추가 화면비를 확인한다. 샘플 값으로 확인한 화면을 실제 다중 PC 매치 검증으로 보고하지 않는다.

시안 이미지를 편집한 것과 Unity에서 구현한 결과를 구분해 전달한다. 승인 시안의 차이가 남아 있으면 구체적으로 적는다. 원본 시안, 실제 캡처, 생성 에셋의 출처와 라이선스를 보존한다. HTML 갱신 시 이미지·폰트가 포함된 canonical portable 파일을 갱신하고 내장 데이터를 확인한다.
