## 1. 세 줄 요약

- **안개 렌더링을 밉맵 기반으로 바꿨다.** CPU 박스 블러 → 셀당 텍셀 1개 마스크 + 셰이더 블러로 옮기는 과정에서 탭 간격이 두 번 틀렸고, 두 번 다 실제 렌더 이미지로 잡았다.

## 2. 안개 렌더링

### 2.1 무엇이 문제였나

`FogRenderer`는 원래 CPU에서 텍셀마다 원을 찍고 박스 블러를 돌렸다. 한 번 칠할 때마다
720×720을 훑어 100ms 넘게 멈췄고, 개척하는 사람이 있는 내내 이동이 끊겼다.

그래서 **CPU는 셀당 텍셀 하나짜리 마스크(240×240 R8)에 0/255만 쓰고, 둥근 가장자리는
셰이더가 만든다**로 바꿨다. 여기까지는 맞는 방향이었는데, "셰이더가 뭉갠다"를 구현하는
과정에서 탭 간격을 두 번 틀렸다.

| 버전 | 탭 방식 | 증상 |
|---|---|---|
| 1차 | 밉 0을 `_BlurTexels`(=2.5) **텍셀 간격**으로 3×3 | 사이 텍셀 1·2를 통째로 건너뛴다. 블러가 아니라 성긴 샘플링이라 반경을 키울수록 **별 모양**으로 각졌다 |
| 2차 | 밉 N을 그 밉의 **텍셀 하나 간격**으로 3×3 | 탭끼리 겹치는 곳이 없어 박스 필터의 사각 발자국이 그대로 **격자**로 드러났다 (밉 2.5 부근에서 뚜렷) |
| 현재 | 밉 N을 그 밉의 **반 텍셀 간격**으로 3×3 | 탭이 겹쳐 박스가 텐트가 된다. 0.5~3 전 구간에서 격자·별 없음 |

**교훈은 하나다. 탭 간격은 샘플링하는 밉의 텍셀 크기보다 작아야 한다.** 같으면 격자가,
크면 별이 나온다. 반경을 키우면 부드러워질 거라는 직관이 두 번 다 틀렸다.

### 2.2 현재 구현

**`Assets/Art/Shaders/FogOfWar.shader`**

```hlsl
float2 texel = _MainTex_TexelSize.xy * exp2(_BlurLevel) * 0.5;
float m = Mask(input.uv, _BlurLevel) * 4.0;   // SAMPLE_TEXTURE2D_LOD
// ... 가우시안 가중치 3×3, /16
float revealed = smoothstep(0.5 - _Softness, 0.5 + _Softness, m);
```

- `_BlurTexels`(텍셀 간격) → **`_BlurLevel`(밉 레벨)** 으로 의미가 바뀌었다. 1 올릴 때마다 평균 범위가 두 배다.
- 넓은 평균은 밉 피라미드가 만들고, 3×3 탭은 박스의 사각 발자국만 지운다.

**`Assets/Scripts/Client/FogRenderer.cs`**

- 마스크가 `mipChain: true` + `FilterMode.Trilinear`가 됐다. Trilinear라야 밉 사이가 계단 없이 이어진다.
- `mask.Apply(false)` → **`Apply(true)`**. 셰이더가 넓은 평균을 밉에서 읽으므로 밉이 낡으면 걷힌 자리가 흐릿하게 남는다.
- `blurCells` → **`blurLevel`** (기본 1.5). `FormerlySerializedAs`는 쓰지 않았다 — 프리팹·씬은 에디터로 재직렬화해 죽은 `blurCells` 키를 지웠다.
- **`OnValidate` 추가.** 머티리얼을 `Build()`에서 한 번만 채우던 탓에 Inspector 실시간 조정이 원래 안 먹었다. 이제 플레이 중에 슬라이더를 돌리면 즉시 반영된다.

### 2.3 `blurLevel` 감각 (실제 렌더 이미지 기준)

| 값 | 결과 |
|---|---|
| 0.5 | 또렷한 원 |
| **1.0~1.5** | **균형점. 현재 값 1.5** |
| 2.0~2.5 | 꽤 뭉갬. 좁게 걷힌 자리는 다시 덮이기 시작 |
| 3.0+ | 작은 개척지는 아예 사라짐 |

넓은 블러가 작은 구멍을 닫는 것은 원리상 당연하다. 밤에 길게 카빙된 동선은 시험용 원보다
크므로 실제 판에서는 이 표보다 덜 닫힐 것으로 보이나, **이는 추정이고 실측하지 않았다.**

### 2.4 UV 뒤집기 — 맞다 (확정)

`mat.mainTextureScale = (-1, -1)`, `offset = (1, 1)`이 필요한 만큼만 되돌린다.
기억이 아니라 Unity 기본 Plane 메시의 UV를 실제로 읽어 대조했다.

```
Plane 원시 UV:  -X→u=1, +X→u=0   |   -Z→v=1, +Z→v=0   (둘 다 반대)
scale(-1,-1) 적용 후:            +X→u+,  +Z→v+
마스크 요구:  index = z*Side + x, SetPixelData는 v=0(아래)부터 채움 → +X→u+, +Z→v+
판정: MATCH
```

**반대편이 걷히는 문제는 없다.** 이 항목은 다시 의심할 필요 없다.

### 2.5 잔여 오류 로그 주의

`FogPlane: 안개 셰이더가 연결되지 않았다`는 **셰이더를 붙이기 전 세션의 잔여 로그**였다.
프리팹·씬 양쪽 다 `guid: 2c3d67480167f0d4eac0a4599cd0cca7`로 정상 연결돼 있다.
Console을 비우지 않으면 해결된 오류를 계속 쫓게 된다.

## 3. 매치 씬 단독 실행 / 개발 콘솔 부팅

### 3.1 원인 (실제로 돌려서 확인)

`NetworkManager`·`SteamLobby`·`MatchSeating`은 전부 **`Assets/Scenes/Launcher.unity`** 에 있고,
`Launcher.Start()`가 자기 자신을 뺀 모든 루트를 `DontDestroyOnLoad`로 넘긴다.
**SampleScene만 열고 재생하면 이들이 없어서 접속도 좌석 배정도 시작 자체가 안 된다.**

막고 있던 것은 둘뿐이었다.

| | 상태 | 설명 |
|---|---|---|
| `EditorSceneManager.playModeStartScene` | 비어 있었음 | 어느 씬에서 재생하든 런처를 먼저 거치게 하는 **Unity 내장 기능** |
| `NetworkAutoStart.enableAutoStart` (Launcher) | **False** | 그래서 자동으로 호스트가 안 뜬다. 로비를 거치려고 꺼 둔 것으로 보고 **건드리지 않았다** |

매치 씬 로드 자체는 새로 만들 필요가 없었다. `SteamLobby.LoadGameSceneServer()`가 서버 기동
이벤트에서 이미 걸어 두고 있고, 주석에도 "개발 HUD의 Host 버튼으로 들어와도 같은 곳으로
가야 한다"고 적혀 있다. **스팀 없는 로컬 테스트 경로는 원래부터 있었다.**

### 3.2 붙인 것 — 개발 콘솔 부팅 패널

재생 **전** 화면(그전까지 안내문만 있던 자리)에 들어간다.

```
팀 수   [2]
내 팀   [0]
[ 검증 시작 (Host) ]
부팅 씬  Launcher   [부팅 씬 해제]
```

동작 순서:

1. 팀 구성을 **`SessionState`** 에 적는다. 재생 진입이 곧 도메인 리로드라 필드에 담으면 버튼을 누른 사실 자체가 사라진다. `SessionState`는 에디터를 닫을 때까지만 남아 프로젝트 파일을 건드리지 않는다.
2. `playModeStartScene = Launcher` → `EnterPlaymode()`.
3. 런처가 깨어나면 `ApplyPendingBoot()`가 `SetTeamCountCheat` → `SetForcedSeatCheat(내 팀)` → `StartHost()`.
4. 호스트가 자기 자리를 받은 것(`PlayerTeam.Local() >= 0`)을 확인한 뒤 **강제 좌석을 자동으로 푼다.**

**4번이 핵심이다.** 강제 좌석을 안 풀면 뒤이어 붙는 MPPM 가상 플레이어까지 같은 팀에
앉아서, `AGENTS.md` QA 게이트가 요구하는 팀 격리 검증이 불가능해진다. 조용히 통과하는
종류의 결함이라 단계를 나눠 두었다.

키: `BB.DevConsole.BootTeams` · `BootMyTeam` · `BootStage`.

### 3.3 개발 콘솔이 재구성 중이다

작업 중 `DevConsoleWindow.cs`가 **그룹 플러그인 구조로 리팩터링**됐다.

```
Assets/Editor/DevConsole/
  DevConsoleGroup.cs      추상 그룹. Tab · Title · Build · Refresh
  DevConsoleState.cs      갱신 한 번의 상태 스냅샷 (Playing/Listening/IsServer/Clock/Seating)
  Groups/SessionGroup.cs  접속 조작
```

부팅 패널은 현재 `DevConsoleWindow.cs` 안에 `RefreshBootGroup`으로 들어가 있다.
**`Groups/BootGroup.cs`로 옮기는 것이 이 구조의 의도에 맞다.** `DevConsoleGroup`의 문서
주석에 새 그룹 만드는 절차가 그대로 적혀 있다.

## 4. 되돌리면 안 되는 것

| 대상 | 값 | 이유 |
|---|---|---|
| `FogPlane` 프리팹 / 씬 인스턴스 | `blurLevel: 1.5` | 셋 다(코드 기본값 포함) 일치시켜 뒀다 |
| `FogRenderer` 마스크 | `mipChain: true`, `Trilinear`, `Apply(true)` | 셋 중 하나만 빠져도 블러가 죽거나 밉이 낡는다 |
| `mainTextureScale = (-1,-1)` | 유지 | §2.4에서 확정. 지우면 반대편이 걷힌다 |
| `EditorSceneManager.playModeStartScene` | **현재 `Launcher`로 걸려 있다** | 이 세션에서 설정했다. Inspector 어디에도 안 보이는 값이라 콘솔 패널에 현재 값과 해제 버튼을 같이 뒀다 |
| `NetworkAutoStart.enableAutoStart` (Launcher) | **False 그대로** | 의도적으로 꺼 둔 것으로 보고 유지. 검증 버튼은 이것과 무관하게 직접 `StartHost()`를 부른다 |

## 6. 바로 다음에 할 일

1. **매치를 실제로 띄운다.** 개발 콘솔 → 팀 수 2 / 내 팀 0 → `검증 시작`. 여기서 §5의 미검증 4건(안개 화면·부팅 E2E·끊김·팀 격리)이 한 번에 풀린다.
2. **끊김을 프로파일한다.** `Apply(true)`의 밉 재생성이 새로 생긴 비용이다. 원래 목적이 끊김 제거였으므로 여기부터 잡는다. 여전히 끊기면 틱레이트·NetworkTransform 보간을 판다.

4. **EditMode 테스트를 돌린다.** 이번 세션 미실행.
5. **Codex QA 회귀.** 역할 분리는 `AGENTS.md`의 QA 게이트 절을 따른다.

## 7. 내가 확인하지 않은 것 — 중요

작업 트리에 **커밋되지 않은 변경이 크게 쌓여 있다.** 이 세션에서 내가 만지지 않았고,
읽지도 않았다. **이 문서는 아래 항목의 상태에 대해 아무것도 보증하지 않는다.**

- `Rules/LootSlots.cs`, `Night/BuriedBag.cs`, `Tests/EditMode/LootSlotTests.cs` (신규)
- `Night/ItemBox.cs`, `PlayerInteract.cs`, `PlayerInventory.cs`, `DashHarass.cs`, `ReturnZone.cs`
- `Client/UI/*` 전반, `PlayerInputRouter`, `MatchHudPresenter/Screen`
- `Player/PlayerMove.cs`, `Core/GamePhase.cs`, `Rules/RandomLoss.cs`
- `Assets/Plugins/Demigiant/` (DOTween 추정), `Assets/Resources/`
- `AGENTS.md` — 「명명 규칙」 절이 추가됐다. **UI 소유 타입은 접두사 `UI`** 이고 기존 타입 개명은 별도 커밋으로 한다. 현재 `BoxLootPopup` 등은 아직 옛 이름이다.

세션 중 한때 `ItemBox`/`PlayerInteract`의 옛 API(`RemainingCount`, `EffectiveSlot`,
`IsSlotVisible`, `SlotContent`, `SelectedSlot`, `MoveSelectionClient`)를 호출부가 물고 있어
컴파일이 8건 깨져 있었다. **지금은 해소됐다.** 새 API는 `SlotCount` / `SlotItem(i)` /
`SlotCountAt(i)` / `RevealedCount` / `IsSlotRevealed(i)` / `TakeSlotClient(i)`다.

또한 `Night/BuriedBag.cs`에 `.meta`가 없어 Unity가 임포트하지 않고 있었다. 강제 refresh로
들어갔다. **새 스크립트를 에디터 밖에서 만들면 이 함정을 다시 밟는다.**
