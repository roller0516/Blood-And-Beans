# (가제) LAST CAFE — 아트 컨셉

> 2D 도트(픽셀 아트). 이 문서는 그림을 그리기 전에 고정해야 하는 규격과 규칙만 다룹니다.
> 근거는 [카페30일-기획서.md](카페30일-기획서.md), 실제 적용 예는 [last-cafe-prototype.html](last-cafe-prototype.html).

---

## 1. 한 문장

**폐허 속의 낙원.** 낮의 카페는 이 세계에서 유일하게 따뜻한 색을 가진 장소이고, 밤은 그 색이 전부 빠진 같은 세계입니다.

이 대비가 아트의 전부입니다. 낮 화면과 밤 화면을 나란히 놓았을 때 **같은 게임으로 안 보이면 성공**입니다.

## 2. 해상도와 픽셀 그리드

| 항목 | 값 | 이유 |
|---|---|---|
| 논리 해상도 | **320 × 180** | 16:9. 배수 확대(2×, 3×, 4×, 6×)로 4K까지 정수 스케일이 떨어집니다 |
| 확대 방식 | 최근접 이웃 (`image-rendering: pixelated`) | 픽셀 경계가 뭉개지면 도트가 아닙니다 |
| 타일 | **8 × 8** | 320×180 = 40 × 22.5 타일. 세로 반 타일은 상단 벽 밴드로 씁니다 |
| 서브픽셀 | **금지** | 좌표는 그릴 때 `Math.round`. 카메라도 정수 픽셀로만 이동 |

**모든 아트는 이 320×180 안에서 최종 확인합니다.** 확대해서 그리는 건 자유지만, 판정은 항상 실제 크기로 합니다.

## 3. 시점 — 낮은 사이드뷰, 밤은 탑다운

기획서 12장의 미결 사항에 대한 답입니다. **둘 다 씁니다.**

| | 시점 | 이유 |
|---|---|---|
| 낮 (카페) | 사이드뷰 (정면 바라보기) | 손님 얼굴·표정·줄이 한눈에 읽혀야 합니다. 접객은 정보 게임입니다 |
| 밤 (좀비 구역) | 탑다운 | 시야 반경, 소음 반경, 좀비 위치가 원으로 표현돼야 합니다. 사이드뷰로는 거리 감각이 안 나옵니다 |

**비용을 분명히 합니다.** 시점이 둘이면 인물 스프라이트도 두 벌입니다. 대신 낮 인물은 정면 1방향, 밤 인물은 상하좌우 중 좌우 2방향(상하는 좌우 스프라이트 재사용)으로 묶어 총량을 억제합니다. 이 게임에서 시점 통일보다 **각 페이즈의 가독성**이 우선입니다.

### 색 사용 규칙 (이게 핵심입니다)

1. **배경은 무채색에 가깝게.** 재·중립 5색과 night-0/1만 씁니다.
2. **채도는 정보다.** amber-3, night-3, blood-2 — 이 세 색은 **플레이어가 반응해야 하는 것**에만 붙습니다. 장식으로 쓰면 화면이 거짓말을 합니다.
3. **낮에는 night-3을, 밤에는 amber-3을 거의 쓰지 않습니다.** 예외는 내 카페(HOME) 표식뿐입니다 — 밤에 유일하게 남은 따뜻한 색이 집이라는 뜻이니까요.
4. 한 스프라이트에 **4색 이하**. 몸통·머리·그림자·강조.

## 5. 인물 스프라이트

| 항목 | 값 |
|---|---|
| 셀 크기 | **8 × 16** (여백 포함) |
| 실제 점유 | 몸통 6 × 9, 머리 4 × 5 |
| 색 수 | 4색 이하 |
| 정렬 | 셀 하단 중앙 = 발 위치 |

### 애니메이션 — 프레임을 늘리지 않습니다

6픽셀 폭 인물에 4프레임 걷기는 낭비입니다. 관절이 안 보입니다.

| 동작 | 프레임 | 비고 |
|---|---|---|
| 대기 | 1 | 2초마다 1픽셀 위아래 호흡(코드로 처리, 프레임 불필요) |
| 걷기 | **2** | 발 좌/우. 초당 6프레임 |
| 달리기 | 2 | 걷기와 같은 프레임, 재생 속도만 2배 + 몸통 1픽셀 앞으로 |
| 제조(바리스타) | 3 | 잔 들기 → 붓기 → 내밀기 |
| 피격 | 1 | 전체를 blood-1로 채운 실루엣. 0.1초 |
| 사망 | 3 | 무릎 → 엎어짐 → 바닥 얼룩 |

**필요하다고 판명되기 전까지 프레임을 추가하지 않습니다.**

### 변형
- 손님: 머리색 3종 × 몸통색 4종 = 12조합을 색 교체로 생성. **스프라이트는 1개.**
- 좀비: 인물 스프라이트에 night-2/night-3 팔레트만 교체 + 걷기 재생 속도 0.6배.
- 플레이어: 몸통 wood-0, 머리 bone-2 고정 — 밤 화면에서 유일하게 밝은 인물이어야 합니다.

## 6. 배경과 소품

- **바닥은 8×8 두 색 체커.** 규칙적인 패턴이 픽셀 게임의 거리 감각을 만듭니다.
- 카페 소품은 8의 배수로: 테이블 16×16, 로스터 16×24, 선반 24×16.
- **디테일은 소품에만.** 바닥과 벽은 최대한 비워 둡니다. 320×180에서 배경이 시끄러우면 캐릭터가 사라집니다.
- 창밖은 항상 잿빛(`soot-3`/`#57493B`)입니다. 카페 안이 따뜻한 건 밖이 그렇지 않기 때문입니다.

## 7. 밤 연출

| 요소 | 규격 |
|---|---|
| 시야 | 플레이어 중심 반경 10px 완전 밝음 → 88px에서 `rgba(4,8,7,.93)`. 원형 그라디언트 |
| 소음 반경 | 걷기 22px(night-3, 알파 .22) / 달리기 55px(blood-2, 알파 .5) 원 외곽선 |
| 좀비 구역 | 반경 58px, night-1 채움 + night-2 점선(3px 대시, 4px 간격) |
| 남의 카페 | **발견 전에는 그리지 않습니다.** 발견 후 blood-2 16×16 + 이름표 |
| 내 카페 | amber-3 16×16. 밤 화면의 유일한 난색 |

시야 밖을 완전한 검정으로 만들지 않습니다(`#0E1614`). 완전 검정은 화면이 꺼진 것처럼 보입니다.

## 8. 텍스트와 UI — 월드에 한글을 그리지 않습니다

320×180에서 한글 최소 가독 높이는 11~12px입니다. 화면 높이의 1/15을 글자 하나가 먹습니다.

**따라서 렌더 레이어를 나눕니다.**

| 레이어 | 내용 | 방식 |
|---|---|---|
| 월드 | 캐릭터, 타일, 이펙트, **아이콘과 색** | 320×180 캔버스 |
| UI | 수치, 이름, 로그, 결산, 메뉴판 | 캔버스 위 별도 레이어 (실제 픽셀 해상도) |

월드에 정보를 표시할 때는 **글자 대신 아이콘과 색**을 씁니다. 손님이 원하는 맛은 한글 태그가 아니라 6×6 아이콘(각설탕/커피콩/레몬/견과/봉인된 캔)으로 표현합니다.

- UI 서체: 픽셀 계열 한글 폰트(갈무리, 둥근모꼴 계열). **라이선스 상업 이용 조건을 반드시 확인**하고 문서에 기록합니다.
- 라틴 문자·숫자 라벨(DAY, SALES, RANK)은 픽셀 서체(Silkscreen 등)로 분리해 대비를 만듭니다.
- 숫자는 자릿수 고정폭(`tabular-nums`). 매출이 흔들리면 싸구려로 보입니다.

## 9. 이펙트

전부 도트로 직접 찍습니다. 파티클 시스템의 부드러운 그라디언트를 쓰지 않습니다.

| 이펙트 | 방식 |
|---|---|
| 판매 성공 | `+15G` 텍스트가 14px/초로 상승, 1.1초간 알파 감소. 적중이면 amber-3, 불일치면 blood-2 |
| 김(수증기) | 2×2 픽셀 3개가 위로 흔들리며 사라짐 |
| 피격 | 화면 전체 1프레임 blood-1 오버레이 + 인물 실루엣 플래시 |
| 상자 개봉 | 뚜껑 1픽셀 위로, 8프레임 후 soot-4로 변색 |
| 습격 진행 | 하단 80×5 게이지. 아이콘 없이 바 하나 |

**화면 흔들림(shake)은 피격과 사망에만.** 남발하면 픽셀 정렬이 무너져 보입니다.

## 10. 하지 않을 것

- 안티앨리어싱, 소프트 그림자, 블러, 블룸 — 픽셀 경계를 흐리는 모든 것
- 도트 위에 얹는 고해상도 UI 아이콘 (해상도가 섞이면 둘 다 싸 보입니다)
- 회전. 스프라이트는 회전시키지 않고 방향별로 그립니다
- 팔레트 밖의 색. "이번만" 쓴 색이 다음 화면에서 기준이 됩니다
- 24색을 넘기기 전에 그림을 늘리기

## 11. 작업 순서

1. **팔레트 스와치 파일**(24색, `.gpl`/`.hex`) — 이게 없으면 아무것도 시작 안 합니다
2. 인물 베이스 1종(대기 1 + 걷기 2) → 색 교체로 손님·좀비 파생
3. 낮 카페 1화면 완성 — 바닥, 카운터, 창, 문, 소품 4종
4. 밤 지면 타일 2종 + 상자 + 카페 표식 2종(HOME/RIVAL)
5. 맛 아이콘 5종 (6×6)
6. 이펙트 5종
7. 여기까지가 MVP. 시설·방어 설비 아트는 그 다음입니다

## 12. 미결

- **인물 두 벌(사이드뷰/탑다운) 비용이 실제로 감당되는지.** 3번 단계 끝나고 판단합니다. 감당 안 되면 낮도 탑다운으로 통일하고, 손님 정보는 아이콘에 전부 싣습니다.
- 한글 픽셀 폰트 라이선스 확정.
- 24색이 부족한 지점이 어디인지 — 4번 단계 이후 실측.
