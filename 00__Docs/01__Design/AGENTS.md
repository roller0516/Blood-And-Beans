# 기획 문서 읽기 지침

**기준 기획서는 `1_기획서/BLOOD & BEAN — 게임 기획서.md` 하나다.** 게임 규칙·수치·페이즈
구조·승리 조건에 닿는 작업을 시작하기 전에 이 파일을 **끝까지** 읽는다. 요약본이나 기억,
이전 세션의 인수인계 문서로 대신하지 않는다.

- 코드와 기획이 다르면 추측으로 한쪽을 바꾸지 말고 차이를 장·절 번호로 보고한다.
- 기획서 14장은 **미결 사항**이다. 여기 있는 값을 확정된 사양처럼 쓰지 않는다. 임시값을
  넣어야 하면 `ponytail:` 주석으로 출처가 미결임을 남긴다.
- 기획서에는 확정된 사양만 적는다 (15장). 제안·권장·검토 의견을 본문에 넣지 않는다.
- 기획서를 고칠 때는 기존 파일을 덮어쓰지 않고 새 버전 파일을 만든다 (15장 버전 규칙).

`2_아트 컨셉/`은 2D 도트 시절 자료다. 렌더링은 **3D 탑다운으로 확정**됐으므로 아트 방향의
근거로 쓰지 않는다. 기획서 12장도 같은 이유로 실제 프로젝트와 어긋나 있다.

저장소 전체 규칙은 루트 `CLAUDE.md`에 있고, 충돌하면 루트가 우선한다.
