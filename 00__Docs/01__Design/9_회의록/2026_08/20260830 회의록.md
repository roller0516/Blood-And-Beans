##### 가방이 제거됐을 때 처리
- 가방이 만약 제거 됐으면
	- 해당 유저는 아무것도 못하고 플레이 방식이 하나로 국한되기 때문에(견제)
		- **귀환 지점으로 돌아가면 가방이 재생성되는 방식**
	- UI 표현
		- 가방 제거
			- **가방 아이콘 X 표시**
			- **귀환 지점으로 돌아가면 다시 가방이 재생성된다는 문구 추가** 
				- **"i" 아이콘을 가방 아이콘에 붙이고, 마우스 갖다대면 문구 뜨도록 하는 것도 가능**

##### 아트 풍 / UI 디자인
- **아트 풍은 아래의 키워드를 메인으로 가져 가보는 걸로 OR 지수님 재량**
	- **3D 카툰, 캐주얼, 파티 게임**
	- Ref. 폴 가이즈, 파티 애니멀즈
	- *최대한 메인 캐릭터의 귀여움을 살려줄 수 있는 아트풍이면 좋을 것 같음(진규)*
- UI는 아트 풍을 정하면 상세 디자인을 진행

##### 카페 기획
- 현재 상세한 카페 기획이 안 나와서 낮 부분의 진행이 막혀있는 상태
	- 빠르게 카페 쪽 기획을 우선 순위로 잡아서 기획서 업데이트 해서 전달
		- 가능하면 UI 레이아웃도
- 뷰를 파티애니멀즈 같은 방식으로 바꾸기로 했기 때문에 이에 맞춰서 플레이 방식도 같이 수정
