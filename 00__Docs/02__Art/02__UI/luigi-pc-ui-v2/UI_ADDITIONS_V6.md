# 2026-10-11 · 루이지 절제형

기존 시안을 보존하고 전체 18개 UI에 「루이지 · 절제형」 선택지를 추가했습니다. 반복 무늬·금속 프레임·두꺼운 장식·상시 발광을 줄이고 짙은 초록/크림색 패널, 둥근 글자, 3D 몬스터를 유지했습니다. 캐릭터·팀 선택은 8인 무대, 제조·완성 판정은 현재 구현 오브젝트를 참고한 추가 시안을 기준으로 정리했습니다.

새 PNG와 생성 프롬프트는 `unity-restrained/`에 있습니다. 공개 갤러리는 기존 주소와 공개 범위를 유지합니다. `claude-import.html`과 독립형 HTML도 갱신했습니다. 각 화면에 접을 수 있는 구현 메모와 전체 구현 가이드를 넣었습니다.

`LUIGI_IMPLEMENTATION_GUIDE.md`에는 실제 프로젝트 컴포넌트와 연결, UI/3D/TMP 분리, PC 크기, 폰트 애셋, 8인 팀 배치에 필요한 추가 작업, 에셋 제작 목록과 적용 순서를 정리했습니다. 이번 작업은 콘셉트 시안·갤러리·문서이며 Unity 게임 에셋은 수정하지 않았습니다.

`gallery-validation-v6.json`은 로컬 HTTP 갤러리에서 18개 이미지, 귀환 3/로딩 2/페이즈 6 상태, 기존 버전, 구현 가이드와 콘솔 오류를 확인한 기록입니다. `portable-validation-v6.json`은 내장 이미지·폰트 정적 확인 기록입니다. Unity 게임 QA와 빌드 검증은 수행하지 않았습니다.

배포용 `assets.zip`과 `blood-beans-luigi-portable.html`은 Git에서 제외해도 됩니다. 새 PNG·폰트·`claude-import.html`·`gallery-assets.json`·`rebuild-portable.py`를 같이 보관하면 다른 PC에서 다시 만들 수 있습니다. 절차는 `REBUILD.md`를 참고합니다. 재생성 스크립트는 사용하지 않는 과거 가방 아틀라스를 제외하고 현재 표시 에셋 137개를 포함합니다.
