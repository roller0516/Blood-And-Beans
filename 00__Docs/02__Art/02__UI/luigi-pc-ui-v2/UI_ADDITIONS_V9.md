# 2026-10-11 · 실제 인게임 구도 + 루이지 강조

직전 실제 인게임 시안은 일반적인 짙은 초록 패널에 가까웠습니다. 실제 카메라 구도를 유지하면서 UI의 개성은 더 강하게 드러나도록 낮 HUD·조합법·주문/인내심·제조/판정을 수정했습니다.

- 검보라색 바탕, 유령 초록, 크림색 글자와 굵은 윤곽을 공통 표현으로 사용합니다.
- 시계는 녹색 알람시계와 흐르는 유령 액체 형태의 프레임, 날짜는 별도 작은 탭입니다.
- 팀 순위는 비대칭 초록 선택표, 매출은 두툼한 금색 코인으로 구분합니다.
- 주문 말풍선과 제조 카드는 굵은 외곽선·불균일한 모서리·짧은 그림자로 정리합니다. 인내심은 기존처럼 말풍선 안에서 채워집니다.
- 조합법은 펼친 책 형태입니다. 초록색 윤곽 제목, 작은 유령 인장, 검보라색 분류표와 가격표를 사용합니다. 음료와 재료는 현재 프로젝트 모델을 렌더한 아이콘입니다.
- 폰트는 Bagel Fat One·Jua·Coiny를 유지하면서 제목과 주요 숫자의 윤곽·그림자·간격을 다시 설계했습니다.

갤러리에서 「실제 인게임 · 루이지 강조」, 「실제 인게임 · 이전 간결형」, 「실제 인게임 원본」을 선택합니다. 이전 간결형은 직전 결과를 비교용으로 유지합니다. 기존 생성 시안·절제형·다른 UI 화면도 유지합니다.

## 구도와 구현

`unity-gameplay/day-base.png` 및 대응하는 배포 WebP는 변경하지 않았습니다. Unity의 게임 화면을 다시 그리거나 장면 색상을 필터링하지 않고 HTML/CSS/SVG UI만 수정했습니다. 수치·주문·아이템·월드 앵커는 같은 `capture.json`을 사용합니다. 낮에 가방을 표시하지 않습니다.

이번 시안의 SVG 아이콘과 프레임은 코드로 작성한 벡터입니다. Unity 적용 시 문자 없는 스프라이트로 분리하고, 특수 실루엣은 9-slice 또는 고정 비율 Image로 준비합니다. 실제 수치와 문구는 TMP로 표시하고, 외곽선과 짧은 그림자는 공용 TMP 머티리얼로 관리합니다. 둥근 공통 면은 기존 부품을 재사용합니다. 자세한 연결은 `LUIGI_IMPLEMENTATION_GUIDE.md`와 V8 문서를 따릅니다.

시각 참조: [Nintendo · Luigi’s Mansion 3](https://www.nintendo.com/jp/switch/ag3ja/index.html). 해당 게임의 로고나 캐릭터 이미지를 갤러리 에셋으로 복사하지 않았습니다.

## 확인 범위

브라우저에서 네 화면의 강조·이전 간결형·원본 전환을 확인했습니다. 주문 3개, 조합법 11개, 제조 게이지 표시 조건, 아이콘 로딩과 콘솔 오류 없음도 확인했습니다. 밤 화면으로 이동하면 추가 레이어가 제거됩니다. 독립형 HTML의 이미지·폰트 내장과 재구성 입력을 확인했습니다. Unity 씬·프리팹·게임 코드는 이번 작업에서 수정하지 않았습니다.

사용 스킬: sites. 이미지 생성은 사용하지 않았습니다.
