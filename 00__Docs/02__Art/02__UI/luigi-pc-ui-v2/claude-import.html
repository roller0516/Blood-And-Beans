배경과 UI의 기준

첨부하신 기존 타이틀의 보랏빛 밤·따뜻한 카페·귀여운 3D 몬스터를 기준으로 합니다. UI는 반투명 보라색 면, 얇은 연보라 선, 흰 글자와 제한적인 연두 선택 표시로 구성합니다. 황동·종이·가죽·클립·사슬 장식을 걷어냈습니다.

낮·밤 시안은 현재 후방 카메라와 공간 배치를 참고해 재해석한 이미지입니다. 같은 낮 배경에 조합법·주문·제조를, 같은 밤 배경에 루팅·밤 부품·귀환을 겹칩니다. 실제 Unity 카메라 캡처나 새 3D 배경 제작 완료를 뜻하지 않습니다.

재사용할 부품

부품분리와 재사용
패널·버튼UISurfacePart와 기존 라운드 표현을 재사용합니다. 기본/선택/호버/비활성은 같은 면의 색·선 상태입니다. 특수 외곽만 9-slice로 제작합니다.
카드·목록UICharacterCard, UICrewRosterCard, UIRoomListRow, UIRoomTeamCard, UIStandingRow의 데이터 연결을 유지합니다.
주문·제조·루팅UICustomerOrder/UIBubbleFill, UIMakingCard/UICompletionGauge, UIBoxLootSlot을 유지합니다. 비교 시트 전체를 PNG 한 장으로 덮지 않습니다.
숫자·문구이름·매출·시간·설명은 TMP로 분리합니다. 생성 이미지의 글자는 실제 폰트 에셋이 아닙니다. 현재 폰트 설정은 기존 캐릭터 시안 및 문자로 만든 귀환/로딩/전환 안내에 적용됩니다.
3D와 아이콘무대와 캐릭터는 실시간 3D로 유지합니다. 컵·재료·가방 아이콘은 실제 모델을 같은 조명에서 렌더링해 Sprite로 사용합니다. 아이콘마다 상시 카메라를 두지 않습니다.

배경의 후속 작업

현재 CharacterStage의 3D 카페와 카메라를 기반으로 배경의 재질·조명·창밖 분위기를 맞춥니다. 새 시안 PNG를 기존 3D 장면 위에 덮지 않습니다. 카페 내부/창밖 숲/보조 조명은 장면 아트 작업이고 UI 패널과 별도로 검토합니다. 플레이 화면의 작업대 위치와 카메라를 바꾸지 않는 범위에서 진행합니다.

실제 적용 순서

  1. 전체 시안의 화면 밀도·패널·배경 분위기를 확정합니다.
  2. 한 화면의 공통 부품과 실제 TMP를 먼저 구현하고 시안과 나란히 비교합니다.
  3. 같은 부품을 메뉴·낮·밤·정산에 적용합니다. 새 Screen 루트를 통째로 복제하지 않습니다.
  4. 배경 3D 아트와 조명을 별도 단계로 맞춥니다.
  5. 실제 해상도·긴 문구·상태·입력·Canvas 갱신·오버드로를 확인합니다. 측정 전 FPS나 완전 일치를 약속하지 않습니다.

새 래스터 시안 15장과 기존 타이틀 1장으로 18개 항목을 구성했습니다. 기본/실패/로딩/카운트다운은 필요한 범위에서 상태 선택으로 비교합니다. 세부 문구와 수치는 예시이며 실제 게임 데이터가 기준입니다.
