# 가벼운 루이지 전체 UI 시안

시안 제작: 2026-10-18. 로컬 갤러리 패키징: 2026-10-19.

기준은 기존 `pcVampire2.png` 타이틀과 캐릭터 시안이다. 보랏빛 밤·따뜻한 카페 조명·귀여운 입체 몬스터는 살리고, 두꺼운 황동·종이·가죽·클립 장식은 걷어냈다. 이 폴더는 검토용 생성 시안이며 Unity 프리팹이나 3D 배경을 새로 구현한 결과가 아니다.

총 18개 항목이다. 15개의 새 생성 이미지와 기존 타이틀 1장을 사용한다. 동적 토스트·로딩·전환 문구는 HTML 폰트 레이어이며 나머지 생성 이미지의 글자는 고정이다. 폰트 비교를 모든 새 래스터 이미지에 적용한 것으로 설명하지 않는다. 부품 비교 시트의 크기와 동시 표시는 실제 HUD 크기·상태가 아니다.

## 실제 제작으로 이어갈 구조

- 기본 면·버튼·선택선은 기존 UISurfacePart/라운드 표현을 사용한다. 특수 외곽만 문자 없는 9-slice로 제작한다.
- 캐릭터·참가자·방 행·팀 카드·순위 행은 기존 Parts와 데이터 연결을 유지한다. 같은 모양을 새 Screen 안에 반복 복사하지 않는다.
- 인내심은 UIBubbleFill의 아래부터 채움, 제조는 UIMakingCard의 두 줄, 루팅은 UIBoxLootSlot 5칸 구조를 유지한다.
- 이름·숫자·설명·상태는 TMP로 분리한다. 생성 이미지에서 글자를 잘라 실사용 폰트로 취급하지 않는다.
- 작은 컵·재료·가방 아이콘은 실제 모델의 통일된 오프라인 렌더를 Sprite로 사용한다. 개별 아이콘에 실시간 Camera/RenderTexture를 붙이지 않는다.
- 기본/선택/호버/비활성은 공용 Sprite/Material의 상태로 만든다. 동적 Canvas 갱신 범위를 좁히고 장식의 Raycast Target을 끈다. 성능 수치는 실제 측정 후 판단한다.

## 3D 배경

메뉴와 캐릭터 무대의 창밖 숲·보랏빛 환경광·따뜻한 실내광은 후속 3D 아트 방향이다. 실제 CharacterStage는 기존 3D 카페·캐릭터·카메라를 기반으로 수정하며 시안 PNG로 덮지 않는다. 낮·밤 플레이는 현재 카메라와 작업 공간을 기준으로 한다. 생성 결과가 현재 Unity와 픽셀 단위로 일치하는 것은 아니다.

UI를 승인한 다음 한 대표 화면을 기존 부품으로 먼저 구현하고, 시안과 실제 프리팹을 나란히 비교한 뒤 공통 부품을 전체 화면에 적용한다. 배경 3D 작업과 UI 구현은 분리해 진행한다.

## 파일과 범위

`provenance.json`에 사용한 참조·프롬프트·생성 방식·한계를 기록했다. `encoding.json`은 원본 해상도를 유지한 무손실 WebP 변환 정보다. `blood-beans-luigi-portable.html`의 기존 「Unity 전체 UI」 항목을 이 시안으로 교체한다. 「이전 Unity 구현」은 과거 프리팹 적용 기록이며 이번 새 시안이 반영된 화면이 아니다.

이번 작업은 로컬 HTML·시안 갱신이다. 공개 사이트 배포, Unity 적용, 브라우저 직접 파일 상호작용 검증, 플레이어 빌드 성능 측정은 포함하지 않았다.

## 2026-10-19 Unity 후속 적용

사용자 승인 후 기존 프리팹을 이 방향으로 수정했습니다. 위 PNG는 계속 생성 시안이며, 실제 결과는 `native-captures/`의 저장 프리팹 렌더와 `runtime-captures/`의 Play Mode 화면입니다. 구현 범위·배선·성능 확인의 한계는 상위 `UI_UNITY_IMPLEMENTATION.md`의 최신 절을 참조합니다.
