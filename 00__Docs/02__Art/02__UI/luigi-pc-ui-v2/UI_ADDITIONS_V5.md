# 루이지 UI 추가 비교안 · 2026-10-10

기존 시안을 보존하고 같은 갤러리와 휴대용 HTML에 다음 선택지를 추가했습니다.

- 캐릭터·팀 선택 → **추가 · 8인 팀 무대**: 4팀 × 2명의 3D 몬스터 캐릭터를 한 무대에 배치한 별도 콘셉트.
- 제조·완성 판정 → **추가 · 구현 오브젝트**: 현재 컵·우유병·원두·초콜릿·블러드 빈·탄 재질의 Unity 렌더링을 참조한 별도 콘셉트. 생성 이미지이며 실제 프리팹과 픽셀 단위로 같지는 않습니다.
- 제조·완성 판정 → **실제 3D 오브젝트**: 현재 ItemVisualConfig의 음료·디저트·재료·식기 24개를 실제 메시와 재질로 렌더링한 비교표.
- 전체 18개 UI → **현재 구현 · 샘플 화면**: 프로젝트의 현재 UI 프리팹에 샘플 데이터를 넣어 렌더링. 귀환 3종, 로딩 2종, 페이즈 6종을 포함해 26개 화면입니다. 화면을 전환해도 공통 비교 모드가 유지됩니다.

## 현재 구현 화면의 범위

실제 네트워크 플레이 세션의 스크린샷이 아닙니다. 프리팹 레이아웃·UI 스프라이트·텍스트 및 표시 함수를 사용하고 순위·재고·준비 인원 등은 비교용 샘플 값입니다. 부품 표는 갤러리용 비교 배치입니다.

낮 배경은 현재 Cafe 프리팹을 갤러리 카메라로 렌더링한 것입니다. 런타임에 생성되는 일부 설비는 포함되지 않습니다. 밤 배경은 현재 열려 있는 Battle_01의 MainCamera 캡처이며, 플레이 중이 아닌 편집 상태의 낮 조명입니다. 실제 밤 플레이 상태를 재현한 캡처로 해석하지 않습니다.

캐릭터 비교는 현재 CharacterVisualConfig에 연결된 Ghost 계열 5종을 사용합니다. 신규 몬스터 스킨 콘셉트와 구분합니다. 모델 카메라·조명·정면 방향은 비교용으로 설정했습니다. CharacterStage의 기존 배경 재질은 URP 미리보기에서 지원되지 않아 배경 무대 메시를 생략했습니다.

음료 프리팹은 실제 3D 메시를 사용하지만 현재 제조 UI의 아이콘은 원래 구현대로 스프라이트입니다. 추가 콘셉트는 음료가 장면의 실제 오브젝트처럼 보이도록 표현을 바꾼 제안입니다.

## 파일과 재현

- `unity-variants/`: 추가 콘셉트 PNG 2장.
- `unity-variants-prompts.json`: 생성 프롬프트.
- `unity-current/`: 구현 UI 26장, 실제 오브젝트 표, 환경 참조, 캡처 목록 및 읽기 전용 캡처 C#.
- `encoding-validation-additions.json`: PNG → 무손실 WebP 변환 29장, 디코딩 후 픽셀 동일성 확인.
- `blood-beans-luigi-portable.html`: 이미지·폰트 내장본.
- `claude-import.html`: 같은 공개 갤러리 이미지·폰트를 참조하는 경량본.

Unity 캡처는 unsaved PreviewScene과 임시 객체를 사용했습니다. 게임 씬·프리팹·스크립트는 수정하거나 저장하지 않았습니다. 캡처 완료 후 Battle_01은 편집 상태, dirty=false이며 사전 존재한 preview scene 1개가 유지되었습니다.

UI 시안 이미지의 문구는 생성 결과이므로 최종 Unity 적용 시 실제 문자열과 TextMeshPro 글꼴로 다시 구현합니다. 휴대용 HTML은 정적 내장 데이터 확인을 수행하며, 브라우저 동작 검증은 로컬 HTTP 갤러리에서 수행합니다.
