# 루이지 콘셉트 강화 · 자유 배치 버전

2026-10-10. 연결 Unity 프로젝트의 화면·기능·표시 조건을 기준으로 18개 시안을 재구성했습니다. 원본 RectTransform 위치를 따르는 방식에서 벗어나 루이지 맨션에서 참고한 가벼운 HUD, 두꺼운 숫자, 유령 호텔의 색과 안내판 형태를 Blood & Beans에 맞게 해석했습니다.

## 갤러리 사용

`blood-beans-luigi-portable.html`의 Unity 전체 UI에서 **새 루이지 시안 / 이전 시안 / 현재 Unity 배치**를 비교합니다. 이전 캐릭터 갤러리와 다른 스타일 갤러리는 보존했습니다. 귀환 3종, 로딩 2종, 페이즈 6종은 상태 버튼으로 비교할 수 있습니다.

## 배치와 시각 규칙

- 타이틀: 좌측 세로 메뉴 + 우측 3D 캐릭터. 기존 중앙 로고·하단 가로 버튼 대신 캐릭터와 메뉴를 나눕니다.
- 입장·캐릭터: 접수대 목록, 선택 캐릭터 확대, 팀별·준비별 정보 분리. 클래스와 종족 외형은 별개입니다.
- HUD: 긴 패널을 없애고 순위·시간·매출을 분리합니다. 낮에는 주문과 조리에, 밤에는 탐색과 적재량에 집중합니다.
- 조합법: 좌측 메뉴판 + 우측 게임 장면. 음료 7종과 디저트 4종, 부족·인기 재료를 유지합니다.
- 정산: 중앙 영수증과 주변 순위·예보·자동 보석 적용. 결과 화면은 실제 집계하는 누적 매출에 집중합니다.
- 색: 어두운 옥색, 크림색, 연두 선택, 소량의 붉은 강조와 코인 금색. 부품 비교 시트는 식별을 위해 확대했습니다.
- 인내심: 별도 수평 바 없이 말풍선 내부를 아래부터 채웁니다. 위쪽 코인 탭은 하나입니다.
- 가방: 밤에만 작게 표시합니다. 빈 가방·가득 참은 닫힘, 중간 적재는 열림, 묻은 가방은 흐리게 + X입니다.

## 서체

| 용도 | 실제 HTML 서체 | 방향 |
|---|---|---|
| 제목·강조 | Bagel Fat One | 두껍고 통통한 한글 |
| 설명·라벨 | Jua | 둥근 손글씨 인상과 가독성 |
| 숫자·영문 페이즈 | Coiny | 둥근 숫자와 진한 외곽선 |

실제 폰트는 HTML과 fonts 폴더에 포함했습니다. PNG 시안 속 글자는 해당 형태를 참고한 생성 레터링이며 정확한 폰트 렌더링은 아닙니다. Unity 적용 시에는 이 폰트와 TextMeshPro 설정으로 다시 구성해야 합니다. 모든 폰트의 OFL 원문·저작권 고지를 함께 보존했습니다.

## 생성물과 검증

`unity-concepts-v2/`에 새 PNG 18장, 생성·수정 기록 prompts.json, 무손실 WebP 인코딩 검증 encoding-validation.json을 저장했습니다. `unity-concepts/`는 이전 버전입니다. WebP는 해상도를 줄이지 않고 픽셀 동일성을 확인했습니다. 그림의 세부 좌표·숫자 막대 길이는 콘셉트 표현이며 생산용 UI에서는 실제 값에 연결합니다.

게임의 씬·프리팹·스크립트는 수정하지 않았습니다. 이번 작업은 시안 갤러리이며, 분리 에셋·9-slice·TMP·PC 앵커 최적화는 실제 적용 단계의 작업입니다.
